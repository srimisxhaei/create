# version.txt-cli

Este repositório contém o código-fonte do livro "version.txt-cli".

This repository contains the source code of the "version.txt-cli" book.

## Requisitos / Requirements

Building requires [frontend]:

```bash
$ cargo install frontend --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ frontend build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ frontend test
```
